# Mental Health Signal — Student Wellness Predictor

Predicts a student's mental health score (0–10) from their social media usage, academic habits, and lifestyle — built as an ML model served through a FastAPI backend, with a plain HTML/CSS/JS frontend.

> This is an informational tool, not a clinical assessment.

## How it works

A regression model is trained on student survey data (screen time, phone unlocks, sleep, study hours, physical activity, stress level, platform used, etc.) using a scikit-learn **Pipeline** with a **ColumnTransformer** for preprocessing. The trained pipeline is saved with `joblib`, then loaded by a FastAPI backend that exposes a `/predict` endpoint. The frontend collects user input through a form and calls that endpoint to display the predicted score.

## Tech Stack

- **Backend:** FastAPI, Uvicorn
- **Validation:** Pydantic (typed request/response schemas, automatic input validation)
- **ML:** scikit-learn (Pipeline + ColumnTransformer), pandas, joblib for model serialization
- **Frontend:** Plain HTML, CSS, JavaScript (`fetch()` used to call the API — no framework)

## API

**POST** `/predict`
Takes: age, gender, country, academic level, most-used platform, purpose of use, daily usage hours, daily unlocks, study hours, physical activity hours, sleep hours, stress level.
Returns: `predicted_mental_health_score` (float, 0–10).

## Running Locally (step by step)

**Requirements:** Python 3.9+ and pip installed on your computer.

### 1. Get the code
Download/clone the repo, then open a terminal inside the project folder (the one containing `main.py`).

### 2. (Recommended) Create a virtual environment
Keeps this project's packages separate from the rest of your system.

```
python -m venv venv
```

Activate it:
- **Windows:** `venv\Scripts\activate`
- **Mac/Linux:** `source venv/bin/activate`

You'll see `(venv)` appear in your terminal prompt when it's active.

### 3. Install dependencies

```
pip install -r requirements.txt
```

This installs: `fastapi`, `uvicorn`, `pydantic`, `joblib`, `pandas`, `scikit-learn`.

### 4. Start the backend server

```
uvicorn main:app --reload
```

- `main:app` → refers to the `app` object inside `main.py`
- `--reload` → auto-restarts the server when you edit code (good for development)

You should see output like:
```
INFO:     Uvicorn running on http://127.0.0.1:8000
```

### 5. Confirm the API is working
Open `http://127.0.0.1:8000` in a browser — you should see the welcome message from the `/` route.

For interactive API docs (auto-generated by FastAPI), visit:
```
http://127.0.0.1:8000/docs
```
Here you can test the `/predict` endpoint directly with sample values before touching the frontend at all.

### 6. Open the frontend
With the backend still running, open `index.html` directly in your browser (double-click it, or right-click → Open with browser).

Since the backend has CORS enabled for all origins (`allow_origins=["*"]`), the page can call the API even when opened as a local file.

> **Note:** `script.js` (not shown to me directly) is what actually sends the request to the backend. It likely points to `http://127.0.0.1:8000/predict`. If your backend runs on a different port or address, that URL inside `script.js` needs to match — share the file with me and I'll confirm/fix this line exactly.

### 7. Use it
Fill in the form (age, gender, country, platform, usage hours, sleep, stress level, etc.) and submit — the predicted mental health score (0–10) should appear on the result panel.

### Stopping the server
Press `Ctrl + C` in the terminal where uvicorn is running.
